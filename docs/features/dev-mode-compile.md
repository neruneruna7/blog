## 課題
まだ公開しない記事と，公開する記事の区別がつかない．
というか，githubにpushしたら全部公開されちゃう．

開発用にまだ公開しないのと，よしOKで公開するのと分けられたらいいよね．そりゃあそうだけど．

## 内容
ArticleConfigにpublish:bool を追加して判定するようにしよう．
- コンパイルコマンドにCLI引数を取れるように．
  - `--release`, `-r` がtrueだったら，publishがtrueのやつだけコンパイル対象にする
  - 指定がなければ，全部コンパイルする．開発モード．
  - rustのcargoに習ったオプション指定．私がRustに慣れているので．
- Source入力をパースした後に，フィルタリングして取り除く．
- これのためのfeatureを作る
  - 規模としてfeatureを作るまでもない気もするけど... なんかフィルターしてるんだなと
  - 命名が重要だ
  - PublicationFilter
  - すでにparsedをfilter関数している処理があるので，もう1つfilterしてそこに関数を渡せばいい．
