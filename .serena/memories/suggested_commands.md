# Suggested Commands

- Build generated metadata: `cargo make build-content`.
- Run content-engine tests: `cargo make test-content`.
- Run full local check: `cargo make check`.
- Remove generated outputs: `cargo make clean`.
- Direct CLI entrypoint: `cargo run -p blog-engine -- build`.
- User shell preference: nushell. Multiline commands can be written as parenthesized command blocks with line breaks.
